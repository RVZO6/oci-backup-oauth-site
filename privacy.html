Privacy policy

Effective October 1, 2026. This policy covers the owner's personal Google OAuth application, OCI Backup Sync, for the OCI Backup Sync (rclone) client.

Purpose and access

This tool is a private automation for its owner's Google Drive account and accesses only the permissions the owner authorizes in the consent screen. The backup client requests Google Drive access to upload, list, verify, and remove encrypted backup repository objects according to the owner's retention policy.

Storage and sharing

Google API credentials are stored on owner-controlled devices. Backup data is encrypted by Restic before upload to Google Drive. This public website does not host backup contents or OAuth credentials. Data accessed by the personal tools is not sold, used for advertising, or made available as a public service. Processing occurs on the owner's devices and the Google services used by the integration.

The integration follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls retention and can delete data or revoke the project's access through Google Account security settings. Revoking authorization alone does not delete existing Google Drive backups.

Contact

For questions, use the project owner's user-support email displayed on the Google OAuth consent screen.
